# UniCORE — Правила и автоматизация проекта

## Профиль проекта
- **Движок**: Godot 4.x (GDScript)
- **Архитектура**: Модульное ядро, Detroit Liquid Glass UI, P2P & Agent
- **Документация**: `ARCHITECTURE.md`, `ROADMAP.md`

---

## Автоматический регламент: «Закрытие Фазы»

Когда пользователь дает команду на завершение/закрытие фазы (например: *"Закрываем Фазу X"*, *"Фаза X готова, пушь"*):

1. **Верификация тестов**:
   - Убедиться, что новые тесты написаны и все существующие тестовые сьюты (`test_*_suite.gd`) валидны и не содержат критических регрессий.

2. **Актуализация `ROADMAP.md`**:
   - Отметить все чек-боксы закрываемой Фазы `[x]`.
   - Обновить блок `## Текущий статус` вверху `ROADMAP.md` (добавить закрытую фазу с 100% готовности).
   - Переключить фокус на следующую фазу.

3. **Формирование Git-коммита**:
   - Добавить измененные файлы через `git add .` (строго соблюдая `.gitignore`, не трогая `.godot/`).
   - Сформировать подробный коммит по стандарту **Conventional Commits**:
     ```
     feat(phase-<номер>): complete Phase <номер> — <Название Фазы>

     - <Список ключевых фич>
     - <Список созданных/измененных модулей и сцен>
     - Status: All tests passed, ROADMAP updated
     ```

4. **Тегирование (Git Tag)**:
   - Создать аннотированный тег релиза, соответствующий версии фазы (например, `git tag -a v0.3.0 -m "Release Phase 3"`).

5. **Отправка на GitHub**:
   - Выполнить `git push origin <текущая_ветка>` и `git push --tags`.
   - Вывести в чат подтверждение с хешем коммита и ссылкой на GitHub.
