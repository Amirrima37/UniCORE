## Implemented architecture and capabilities

`structural_display.gd` builds exterior triangles from solver connectivity and preserves owning elements. Displacement magnitude is computed from stored vectors, normalized in CPU double precision and interpolated as a scalar in the fragment shader before color mapping. HEX8 quad surfaces use triangulated linear interpolation (not full HEX8 shape-function evaluation). Stress stays discontinuous and constant over each owning element face. No averaging, extrapolation or inferred integration-point output is introduced. Missing/nonfinite scalar values are magenta; nonfinite displacement and invalid IDs reject rendering. Automatic finite extrema, clamped endpoints, constant-field midpoint colors, Viridis, five numerical legend ticks and precision tooltips are implemented. Existing registry result commands dispatch unchanged.

Deformation uses original coordinates plus scale times physical displacement on every update. Scale 0 is undeformed and 1 is true scale. An optional undeformed boundary wireframe is available. Solid CAD bodies are hidden while valid results are shown so they cannot mask contours. Existing numerical probes remain unchanged. Legend occupies the scrolling inspector rather than a dedicated viewport overlay; scale controls can require scrolling at 720p.

## Mesh-quality investigation

Source criterion in `mesh_display.gd`: warning if scaled_jacobian < 0.2 OR longest/shortest edge ratio > 5. Invalid/nonfinite, negative determinant and relative degeneracy are separate statuses. TET4 determinant is a·(b×c), volume determinant/6, both m³. Its scaled Jacobian is determinant/(|a||b||c|) at vertex 0, dimensionless but vertex-order dependent; it is not a minimum-over-corners normalized tetrahedron quality. HEX8 samples at eight Gauss points. The UI calls longest/shortest edge ratio aspect_ratio; this is not a general circumradius/inradius aspect metric. No threshold changed. Exactly which criterion each of the 2,688 screenshot elements fails has NOT been measured in this increment; the cylinder investigation remains incomplete. No claim of false positives or mesher improvement is made.

## Continuation — provenance, cylinder quality, viewport inspection

### Import provenance

New jobs save provenance version 1 with SHA-256 of the exact job bytes and a canonical JSON snapshot digest covering revision, parts/materials/conditions, base mesh, exported numerical mesh, analysis and boundary groups. Canonicalization includes a JSON round trip to remove integer-versus-float serialization differences. The native writer adds `provenance_version` and a string `input_fingerprint` to schema 1 results, using the existing exact-byte FNV-64 input fingerprint; its signed decimal encoding avoids JSON double precision loss. No input grammar, checkpoint grammar or solver computation changed. Release standalone build succeeded.

Import verifies snapshot digest, job digest, native fingerprint, field lengths, tensor/vector widths and finite mandatory fields. Import into the active workspace additionally compares current revision, parts, mesh and analysis. Ordered arrays make changed node order/connectivity detectable. Imported results retain material-region ownership and a base-mesh digest, checked when determining whether results remain current. These are accidental mismatch/integrity protections, not adversarial authentication or a cryptographic signature; FNV is not collision resistant.

Compatibility: schema 1 remains additive and older readers can ignore metadata; existing native input/checkpoint formats remain usable. Historical results without provenance are retained but FAIL CLOSED for visualization with an explicit re-solve message. They are not silently certified or deleted. Transparent display of unverifiable legacy files is deliberately unavailable. Current-project import now rejects archived jobs from another revision rather than replacing the active project. A separate verified archive-opening workflow is remaining work.

`test_stage5_provenance.gd`: valid cylinder import, changed coordinates/node order, changed connectivity, changed ownership, snapshot revision, current revision, job bytes, swapped-result fingerprint, malformed tensor width and legacy rejection. Valid output passes after full JSON round trip. Early attempts exposed canonicalization differences and were corrected; failed attempts are not counted as passes.
